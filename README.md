# 🤖 JUEGO | INFINITY RUN 2D | ING. EN VIDEOJUEGOS

¡Bienvenidos al proyecto de **Infinity Run 2D**!

Este proyecto fue desarrollado con fines educativos para estudiantes de **Ingeniería en Videojuegos**, como parte de la materia **Tecnología de Programación en Videojuegos**.

A través de este ejercicio podrás explorar cómo se construye un videojuego del género *endless runner*, utilizando tecnologías web y una estética visual basada en pixel art.

## 🎯 Objetivo del proyecto

Desarrollar un videojuego funcional de desplazamiento infinito para poner en práctica los fundamentos de la programación de videojuegos, mediante la implementación de sus mecánicas y recursos gráficos.

## 🛠️ Tecnologías utilizadas

- **Tecnología principal:** HTML
- **Tipo de proyecto:** Videojuego 2D
- **Estilo visual:** Pixel art
- **Género:** Endless runner
